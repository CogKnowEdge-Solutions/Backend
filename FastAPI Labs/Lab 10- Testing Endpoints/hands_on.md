# Hands-On Lab

Now that you have reviewed the lab lesson, this hands-on activity lets you apply the concepts you covered in the lab. This guided activity walks you through the implementation step by step. Once you have completed it, move on to the separate **Assignment** for unguided practice.

1. Download the attached `.ipynb` file from `attachments/Resources`. This lab is notebook-only; no `.py` version is provided, and the lab must not be converted into a Uvicorn server exercise.
2. Open the notebook in Google Colab, Jupyter Notebook/JupyterLab, or Visual Studio Code.
3. Run the dependency cell first, restart the notebook environment if needed, and then run all cells from top to bottom. The tests use FastAPI's in-process `TestClient`, so no separate Uvicorn server is required.
4. Save the completed `.ipynb` file and upload it back on Learnyst for review.

> **You're done when:** every notebook cell has run without unresolved errors and all guided tests produce the expected results.
>
> **Need help?** If you have trouble setting up the environment or IDE, refer to the **Environment Setup Guide**. For general help with running a FastAPI application with Uvicorn in other labs, refer to **Reference — Running FastAPI Labs: Notebook or Real Server**.
