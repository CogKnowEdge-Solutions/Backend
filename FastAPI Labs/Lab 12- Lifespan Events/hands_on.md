# Hands-On Lab

Now that you have reviewed the lab lesson, this hands-on activity lets you apply the concepts you covered in the lab. This guided activity walks you through the implementation step by step. Once you have completed it, move on to the separate **Assignment** for unguided practice.

1. Download the attached `.py` or `.ipynb` file from `attachments/Resources`.
2. Choose the format you want to use:
   - For a `.ipynb` file, open it in Google Colab, Jupyter Notebook/JupyterLab, or Visual Studio Code, and run the cells from top to bottom.
   - For a `.py` file, open the lab folder in a local Python IDE, configure the required environment, and run the FastAPI app.
   - When both formats are supplied, use the notebook for guided checks and the Python file when you want to exercise the real-server version.
3. Follow the instructions and demonstrations in the selected file. Complete every guided example and verify its expected output.
4. Save your completed work and upload the same format you selected—the `.py` or `.ipynb` file—back on Learnyst for review.

> **You're done when:** the selected lab file runs without unresolved errors and every guided example produces the expected result.
>
> **Need help?** If you have trouble setting up the environment or IDE, refer to the **Environment Setup Guide**. For help running a FastAPI application with Uvicorn, refer to **Reference — Running FastAPI Labs: Notebook or Real Server**.
