# Hands-On Lab

Now that you have reviewed the lab lesson, this hands-on activity lets you apply the concepts you covered in the lab. This guided activity walks you through the implementation step by step. Once you have completed it, move on to the separate **Assignment** for unguided practice.

1. Download the attached `.py` or `.ipynb` file from `attachments/Resources`.
2. Run this lab locally:
   - For a `.ipynb` file, open it in Jupyter Notebook/JupyterLab or Visual Studio Code; do not use a cloud-hosted IDE such as Google Colab.
   - For a `.py` file, open the lab folder in a local Python IDE and run the FastAPI app with Uvicorn.
3. Follow the instructions in the selected file without skipping the server setup. In the notebook, run the dependency cell and all cells from top to bottom, keeping the Uvicorn server cell before the client demonstration cells. For the Python file, start Uvicorn from a local terminal and follow **Reference — Running FastAPI Labs: Notebook or Real Server** to run the application.
4. Save your completed work and upload the same format you selected—the `.py` or `.ipynb` file—back on Learnyst for review.

> **You're done when:** the selected lab file runs without unresolved errors, the local server is reachable, and every guided example produces the expected result.
>
> **Need help?** If you have trouble setting up the environment or IDE, refer to the **Environment Setup Guide**. For help starting or troubleshooting the Uvicorn server, refer to **Reference — Running FastAPI Labs: Notebook or Real Server**.
